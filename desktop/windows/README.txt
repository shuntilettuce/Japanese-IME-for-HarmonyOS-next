shunti IME (Windows 版) トライアル

shuntelligenceでかな漢字変換をする日本語入力です。変換はすべてこのパソコンの中で行い、
打った文字をインターネットに送ることはありません (通信する機能を持っていません)。


■ 入れ方

1. zip を右クリック →「すべて展開」
2. 展開したフォルダの install.bat をダブルクリック
   ・「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」
   ・「このアプリがデバイスに変更を加えることを許可しますか?」と出たら「はい」
3. 「shunti IME を入れました。」と出たら、何かキーを押して閉じる
4. Windows キー + スペース を押して「shunti IME」に切り替える

すでに開いていたアプリでは、開き直すと使えるようになります。


■ 使い方

・ローマ字で打つと変換の候補が出ます
    Tab か ↓ で候補を選び、Enter で確定
・スペースで変換
    スペース・↓・↑ で候補を選ぶ、1〜9 でも選べる
    ← → で文節を選ぶ、Shift + ← → で文節を伸び縮み
    Enter で確定、Esc でかなに戻す
・長く打つと、前の方から自動で確定していきます (スマホ版と同じ)
・無変換キー: 押すたびに カタカナ → 半角カタカナ → ひらがな
・半角/全角キー (または Alt + `) で 日本語入力 のオン・オフ
・大文字で打ち始めると英字のまま (Google 等)
・括弧は 24 種類すべて打てます。[ で「 を打ってスペースを押すと （ ( 『 【 〘 « などが並び、
  「かっこ」と打つと （）「」 などの組が並びます


■ 設定

タスクバーの Zori-chan を右クリック →「設定・ユーザー辞書」、またはスタートメニューの「shunti IME の設定」。
候補ウィンドウの色 (ライト・ダーク)、句読点、ユーザー辞書、学習のリセットなど。


■ 手書き入力

タスクバーの Zori-chan を右クリック →「手書き入力」。読みが分からない字を 1 字ずつ書いて、下の候補を押すと入力欄に入ります。
認識は Windows の日本語の手書き認識を使います。動かないときは、Windows の設定 → 時刻と言語 → 言語と地域 →
日本語の「…」→ 言語のオプション で「手書き」を入れてください。

■ クリップボードの履歴
タスクバーの Zori-chan を右クリック →「クリップボードの履歴」(ショートカットキーにも割り当てられます)。
コピーした文・画像・ファイルが並び、押すと今の入力欄に貼り付けます。右クリックで大きな見本と「固定」「消去」。
履歴はこのパソコンの %APPDATA%\shunti IME\clips にだけ保存します (固定以外は 50 件・30 日まで。外には送りません)。
パスワード管理ソフトなどが「履歴に入れない」印を付けたものは残しません。設定の「クリップボードの履歴を残す」で止められます。


■ 外し方

展開したフォルダの uninstall.bat をダブルクリック


■ 覚えていること

変換で選び直した語は学習して、次から先に出します。
学習は %APPDATA%\shunti IME に保存しています。


■ 動く環境

Windows 10 / 11 (64 ビット版)。ARM のパソコンのアプリの一部では使えません。
